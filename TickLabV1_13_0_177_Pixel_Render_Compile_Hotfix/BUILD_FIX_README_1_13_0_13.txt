TickLab v1.13.0.13 build steps

1. Extract outside OneDrive, preferably C:\TickLab\TickLabV1_13_0_13.
2. Close every running TickLab, dotnet and Visual Studio process.
3. Delete src\TickLab.App\bin and src\TickLab.App\obj if they exist.
4. Open TickLabV1_13_0_13.sln.
5. Select Release | Any CPU.
6. Build > Clean Solution, then Build > Rebuild Solution.
