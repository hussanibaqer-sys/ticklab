TickLab v1.13.0.10 build steps
==============================
1. Close TickLab and Visual Studio.
2. Extract this folder outside OneDrive, preferably C:\TickLab\TickLabV1_13_0_10.
3. Delete src\TickLab.App\bin and src\TickLab.App\obj if they exist.
4. Open TickLabV1_13_0_10.sln.
5. Select Release | Any CPU.
6. Build > Clean Solution, then Build > Rebuild Solution.
