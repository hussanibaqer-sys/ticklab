TickLab v1.13.0.8 build steps

1. Extract the full package outside OneDrive, for example:
   C:\TickLab\TickLabV1_13_0_8
2. Close older TickLab and Visual Studio windows.
3. Open TickLabV1_13_0_8.sln in Visual Studio 2022.
4. Select Release | Any CPU.
5. Build > Clean Solution.
6. Build > Rebuild Solution.

This Linux validation environment cannot execute the final Windows WPF compiler. Visual Studio on Windows remains the final compile test.
