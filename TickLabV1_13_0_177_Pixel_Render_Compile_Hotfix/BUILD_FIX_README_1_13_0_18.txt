TickLab v1.13.0.19 build instructions

1. Close TickLab and Visual Studio.
2. Extract outside OneDrive, for example C:\TickLab\TickLabV1_13_0_19.
3. Delete src\TickLab.App\bin and src\TickLab.App\obj if present.
4. Open TickLabV1_13_0_19.sln in Visual Studio 2022.
5. Select Build > Clean Solution.
6. Select Build > Rebuild Solution.
7. Test horizontal zoom at about 206, 250, 300, 400, 450 and 500 bars.
