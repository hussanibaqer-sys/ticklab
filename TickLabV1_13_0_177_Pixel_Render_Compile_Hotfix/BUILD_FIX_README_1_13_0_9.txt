TickLab v1.13.0.9 build steps

1. Close Visual Studio and every TickLab window.
2. Extract the ZIP outside OneDrive, for example:
   C:\TickLab\TickLabV1_13_0_9
3. Open TickLabV1_13_0_9.sln in Visual Studio 2022.
4. Select Release | Any CPU.
5. Choose Build > Clean Solution.
6. Choose Build > Rebuild Solution.
7. Start without debugging for the first visual test.

If Visual Studio keeps stale generated files, close it, delete the project's bin and obj folders, reopen the solution and rebuild.
