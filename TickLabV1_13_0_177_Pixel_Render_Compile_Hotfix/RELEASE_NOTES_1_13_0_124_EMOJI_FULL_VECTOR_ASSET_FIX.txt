TickLab v1.13.0.124 — Emoji Full Vector Asset Fix

BASE
- Built from v1.13.0.123.

ROOT CAUSE FIXED
- The Emoji catalog was complete, but many cells still depended on the local Windows emoji font.
- On PCs whose Segoe UI Emoji build does not contain a sequence, WPF displayed a tofu/empty rectangle.
- v1.13.0.124 removes the system-font dependency for Emoji-folder previews and chart rendering.

FULL OFFLINE VECTOR ARTWORK
- TickLab now bundles vector artwork for all 3,944 Emoji 17 fully-qualified catalog sequences.
- Every catalog mark resolves to a bundled SVG entry: 3,944 / 3,944, 0 missing.
- No .ttf/.otf/.woff font files are included.
- 3,624 assets use native Twemoji color vector layers.
- 320 newer/unsupported sequences use locally generated vector-path artwork from Noto Color Emoji rendering.
- Picker and chart use the exact same bundled asset loader, so a menu item cannot render as a Windows missing-glyph rectangle.

PERFORMANCE

- Individual emoji DrawingImages are parsed/cached only when visible/used.
