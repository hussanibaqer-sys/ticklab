TickLab v1.13.0.45 build instructions

1. Extract the complete folder to a local non-cloud path, for example C:\TickLab\v1.13.0.45.
2. Open TickLabV1_13_0_45.sln in Visual Studio 2022.
3. Select Release and the correct Windows platform.
4. Choose Build > Clean Solution.
5. Choose Build > Rebuild Solution.

Alternative: double-click Clean-Restore-Build.cmd from a Developer Command Prompt environment.
