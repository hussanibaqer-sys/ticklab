TickLab v1.13.0.4 build steps
================================
1. Close Visual Studio.
2. Do not copy files from an older TickLab source folder.
3. Extract this ZIP to C:\TickLab\TickLabV1_13_0_4 outside OneDrive.
4. Open TickLabV1_13_0_4.sln.
5. Select Release.
6. Choose Build > Clean Solution.
7. Choose Build > Rebuild Solution.
