TickLab v1.13.0.12 build steps

1. Close TickLab and Visual Studio.
2. Extract outside OneDrive, preferably to C:\TickLab\TickLabV1_13_0_12.
3. Delete src\TickLab.App\bin and src\TickLab.App\obj if present.
4. Open TickLabV1_13_0_12.sln.
5. Select Release | Any CPU.
6. Build > Clean Solution, then Build > Rebuild Solution.
