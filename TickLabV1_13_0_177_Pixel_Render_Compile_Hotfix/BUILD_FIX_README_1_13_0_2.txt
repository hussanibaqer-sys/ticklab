TickLab v1.13.0.2 build steps

1. Close Visual Studio.
2. Delete or rename the previously extracted TickLab v1.13.0.1 folder.
3. Extract this ZIP to C:\TickLab\TickLabV1_13_0_2 outside OneDrive.
4. Open TickLabV1_13_0_2.sln.
5. Select Release.
6. Choose Build > Clean Solution.
7. Choose Build > Rebuild Solution.

This package fixes the fillOpacity scope error and the reported nullable diagnostics.
Do not copy individual .cs files from the broken folder into this package.
