TickLab v1.13.0.17 build instructions

1. Extract outside OneDrive, for example C:\TickLab\TickLabV1_13_0_17.
2. Close every running TickLab instance.
3. Delete src\TickLab.App\bin and src\TickLab.App\obj if present.
4. Open TickLabV1_13_0_17.sln in Visual Studio 2022.
5. Select Build > Clean Solution.
6. Select Build > Rebuild Solution.
