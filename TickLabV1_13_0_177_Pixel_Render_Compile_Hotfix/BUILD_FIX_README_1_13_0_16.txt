TickLab v1.13.0.17 build instructions

1. Close TickLab and Visual Studio.
2. Extract outside OneDrive, preferably C:\TickLab\TickLabV1_13_0_17.
3. Delete old bin and obj folders if they exist.
4. Open TickLabV1_13_0_17.sln in Visual Studio 2022.
5. Select Build > Clean Solution.
6. Select Build > Rebuild Solution.

Do not mix files from v1.13.0.15 and v1.13.0.17.
