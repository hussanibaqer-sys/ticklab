TickLab v1.13.0.20 build steps

1. Close TickLab and Visual Studio.
2. Extract outside OneDrive, for example C:\TickLab\TickLabV1_13_0_20.
3. Delete every bin and obj folder inside the extracted source.
4. Open TickLabV1_13_0_20.sln in Visual Studio 2022.
5. Build > Clean Solution.
6. Build > Rebuild Solution.
