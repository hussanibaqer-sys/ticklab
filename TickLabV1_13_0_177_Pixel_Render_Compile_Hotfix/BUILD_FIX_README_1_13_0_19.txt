TickLab v1.13.0.19 build steps

1. Close TickLab and Visual Studio.
2. Extract the package outside OneDrive, for example C:\TickLab\TickLabV1_13_0_19.
3. Delete src\TickLab.App\bin and src\TickLab.App\obj if they exist.
4. Open TickLabV1_13_0_19.sln.
5. Choose Build > Clean Solution, then Build > Rebuild Solution.
